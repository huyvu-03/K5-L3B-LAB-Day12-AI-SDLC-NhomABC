## 2. Bằng Chứng Nghiệm Thu Headless (File Kho Cá Thể Contract v1.2)

- **Lệnh thực thi:**
```bash
python -m chonoi.headless --mode gather --seed 1 --ticks 1 \
  --scenario docs/proof/phase-3/m2_dock_scenario.json \
  --inputs docs/proof/phase-3/m2_dock_inputs.json \
  --out docs/proof/phase-3/m2_gather_dock.jsonl \
  --inventory-out docs/proof/phase-3/m2_catch_p3.json
```
- **File kho xuất ra (`docs/proof/phase-3/m2_catch_p3.json`):**
```json
{"items":[{"id":"I1","kind":"ca_linh","fresh":99.991667},{"id":"I2","kind":"ca_keo","fresh":99.991667}]}
```

File kho hoàn toàn khớp chuẩn Contract v1.2, các cá thể được sắp xếp theo `id` tăng dần, và độ tươi phản ánh chính xác sau 1 tick mô phỏng.
