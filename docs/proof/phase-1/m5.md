## 2. Lệnh chạy & kiểm chứng `chonoi.live`

### 2.1. Chạy bộ test tự động của `chonoi.live` (`test_live` & `test_live_m5`)
```bash
PYTHONPATH=tests:. python3 -m unittest tests.test_live tests.test_live_m5 -v
```
Kết quả:
```text
test_state_input_and_clean_stop (test_live.LiveServerTest.test_state_input_and_clean_stop) ... ok
test_gather_hud_and_static_assets_serving (test_live_m5.LiveM5Test.test_gather_hud_and_static_assets_serving) ... ok
test_quan_live_hud_state_and_inputs (test_live_m5.LiveM5Test.test_quan_live_hud_state_and_inputs) ... ok
----------------------------------------------------------------------
Ran 3 tests in 0.28s

OK
```

### 2.2. Lệnh khởi chạy `chonoi.live` ở cả 2 chế độ
- **Buổi sáng (`gather` — Lặn & Hái, có hình nền `/assets/gather_bg.png`)**:
  ```bash
  python3 -m chonoi.live --mode gather --seed 1 --port 8000 --inventory-out kho.json
  ```
- **Buổi tối (`quan` — Quán ăn nhà bè Má Tư)**:
  ```bash
  python3 -m chonoi.live --mode quan --seed 1 --port 8001 --inventory docs/contracts/inventory.sample.json
  ```
