## 2. Bằng chứng kiểm thử Smoke 2 tiến trình (Gather $\rightarrow$ Quán với 6 nguyên liệu)

Lệnh chạy tích hợp bàn giao kho thực tế:
```bash
python -m chonoi.headless --mode gather --seed 42 --scenario docs/proof/phase-2/m2_dock_scenario.json --inputs docs/proof/phase-2/m2_dock_inputs.json --ticks 1 --out docs/proof/phase-2/m2_gather_dock.jsonl --inventory-out docs/proof/phase-2/m2_catch_p2.json
python -m chonoi.headless --mode quan --seed 42 --inventory docs/proof/phase-2/m2_catch_p2.json --ticks 1 --out docs/proof/phase-2/m2_quan_from_catch.jsonl
```

### Kết quả xuất file kho ([m2_catch_p2.json](m2_catch_p2.json)):
```json
{"items":{"bong_dien_dien":1,"bong_sung":1,"ca_keo":1,"ca_linh":1,"ca_loc":1,"keo_neo":1}}
```

### Snapshot quán ăn nhận kho bàn giao ([m2_quan_from_catch.jsonl](m2_quan_from_catch.jsonl)):
```json
{"type":"snapshot","tick":0,"sim_tick":0,"mode":"quan","phase":"quan","phase_tick":0,"state":"playing","time_left_ticks":10800,"money":0,"earned":0,"reputation":3.0,"score":300,"player":{"pos":[8.0,5.0]},"stock":{"bong_dien_dien":1,"bong_sung":1,"ca_keo":1,"ca_linh":1,"ca_loc":1,"keo_neo":1},"hand":null,"stoves":[{"id":"B1","pos":[2,8],"state":"idle","dish":null,"cook_ticks_left":0,"ready_ticks":0}],"tables":[{"id":"T1","pos":[9,2],"customer_id":null}],"customers":[]}
```
$\rightarrow$ **Quán ăn nhận đầy đủ 100% kho gồm cả 6 loại nguyên liệu v1.1.**
